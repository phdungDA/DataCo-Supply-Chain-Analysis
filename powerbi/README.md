# Power BI

`dataco_supply_chain_dashboard.pbix` (data embedded; open in Power BI Desktop).

| Page | Content |
|---|---|
| Sale Report | Revenue, profit, quantity, % DIFOT cards; revenue by year, region, type, delivery status, category x shipping mode; product detail table |
| Delivery Report | Late Delivery Rate card and trend, order sales, delivery status donut, delivery status x shipping mode, average shipping days by mode, real vs scheduled days |
| Customer Segment | Customers, AOV, average profit per customer; revenue by segment; customers by state/country; profit by segment and quantity |
